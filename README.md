# NexusOps — Security Incident Management Platform

## Project Overview

NexusOps is a personal software engineering portfolio project focused on building a security incident management and operations platform.

The goal is to help security teams organize, classify, investigate, and track security incidents through a structured workflow.

**Current status:** Python foundation and prototype development.

## Planned Core Features

- Incident registration and management
- Automated incident severity classification
- Incident status and lifecycle management
- Analyst assignment and investigation tracking
- Role-based access control
- Audit history
- REST API using FastAPI
- PostgreSQL database integration
- Automated testing

These features are planned and are not all implemented yet.

## Technology Stack

**Currently used:**
- Python
- Git and GitHub

**Planned:**
- FastAPI
- PostgreSQL
- SQLAlchemy
- pytest
- GitHub Actions

## Current Implementation

The repository currently contains Python learning prototypes demonstrating:

- Conditional incident severity classification
- Batch incident processing
- Functions and dictionaries
- Input validation and exception handling
- Object-oriented incident models
- Python module imports

## Development Roadmap

1. Python foundations and Git version control
2. Database design and SQL fundamentals
3. FastAPI incident management endpoints
4. Database persistence
5. Authentication and authorization
